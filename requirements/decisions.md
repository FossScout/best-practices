# Requirements Best Practices: Final Decisions

Default rules to follow unless explicitly overridden.

## Identification
- **Decision**: Unique ID + structured template (Option A)

## Change Management
- **Decision**: Change request + impact analysis + approval (Option A for regulated; Option B for agile)

## Deletion & Obsolescence
- **Decision**: Mark obsolete, never hard-delete (Option A)

## Versioning & History
- **Decision**: Semantic versioning per requirement + git history (Option A)

## Traceability
- **Decision**: Bidirectional matrix for regulated; ID linking minimum (Option B minimum)
