# Release Management: Final Decisions

Default rules to follow unless explicitly overridden.

## Versioning
- **Decision**: SemVer for libraries; CalVer/git SHA for services

## Changelog
- **Decision**: Keep a Changelog + auto-generation (Option A)

## Feature Flags
- **Decision**: Feature flag service for prod (Option A); config-based for small apps (Option B)

## Release Process
- **Decision**: Checklist + approval gate + rollback plan + post-release monitoring
