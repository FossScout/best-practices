# Architecture Best Practices: Final Decisions

Default rules to follow unless explicitly overridden.

## Clean Architecture
- **Decision**: Domain framework-free; dependency inversion; use cases

## ADRs
- **Decision**: Record significant decisions; never delete, mark superseded

## Modular Monolith
- **Decision**: Default to modular monolith (Option A); split only when needed

## Microservices
- **Decision**: Extract from modular monolith only when justified
